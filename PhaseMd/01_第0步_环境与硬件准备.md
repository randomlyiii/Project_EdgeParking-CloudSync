## 0.3 接线总表（唯一权威接线参照，逐项打钩）

### P0-04 CAN 总线（通道 0）⬜

| MP157 侧 | 中间 | C8T6 侧 |
|---|---|---|
| FDCAN1 **PD0=RX / PD1=TX**（AF9） | 板载 TJA1042 → CANH/CANL 端子 | **PA11=RX / PA12=TX** → TJA1050 |
| 端子 CANH ↔ | 总线 CANH | TJA1050 CANH |
| 端子 CANL ↔ | 总线 CANL | TJA1050 CANL |
| GND ↔ | **必须共地** | GND |

- 断电量 **CANH–CANL 电阻 ≈ 60Ω**（两 120Ω 并联）。
- 波特率两端 **500 kbps**：C8T6 = 36M/9/(1+5+2)；MP157 = 见 03 文档 P2-06。

### P0-05 C8T6 本地外设 ⬜

| 器件 | 引脚 | 说明 |
|---|---|---|
| OLED SSD1306 | **PB8=SCL / PB9=SDA**（软件 I2C，GPIO 开漏） | 0x3C，✅ 已点亮 |
| BH1750 | **同一条 PB8/PB9 总线**，ADDR 悬空=0x23 | 3.3V，与 OLED 共用不冲突 |
| SG90 | 信号 **PA0**（TIM2_CH1 PWM，CubeMX 待添加） | 独立 5~6V 供电 + 共地 |
| PC13 | 板载 LED | 心跳/诊断闪码 |

### P0-06 K210 ↔ MP157 UART（通道 2）⬜

| K210 | MP157 A7(Linux) |
|---|---|
| TX | 选定 UART 的 RX（底板排针选一路 3.3V TTL，**记录设备名**如 `/dev/ttySTM1`） |
| RX | TX ｜ GND ↔ GND（共地） |

- 电平均 3.3V TTL；波特率 921600 起步（目标 1.5Mbps 实测定）。
- 先用 USB-TTL 直连 PC 验证 K210 输出（06 文档 P5-08），再上板。

### P0-07 供电规划 ⬜
- 舵机独立 5~6V ≥2A（启动电流大，勿与 C8T6 共 LDO）。
- CAN 联调时 MP157 / C8T6 / 舵机电源**三共地**。
