### P1-05 遮光状态机（百分比掉点 + 回滞去抖）🟨（2026-09-06 代码已就绪，待烧录验证；与 CAN 上报一同落地）
放 `freertos.c` 或新建 `shade.c`，`BH1750_Task` 每 200ms 调一次：

```c
typedef enum { SHADE_CLEAR = 0, SHADE_SHADED } shade_state_t;
static shade_state_t s_state = SHADE_CLEAR;
static float    s_baseline = -1.0f;   /* -1=未初始化，首采样直接赋值 */
static uint8_t  s_confirm  = 0;

/* 返回 1=进入遮光(边沿)  -1=恢复(边沿)  0=无变化 */
int8_t Shade_FSM_Update(uint16_t lux)
{
    if (s_baseline < 0) { s_baseline = lux; return 0; }
    int32_t drop = 0;
    if (s_state == SHADE_CLEAR) {
        if (lux >= s_baseline)  s_baseline = lux;                /* 变亮快速跟上 */
        else                    s_baseline = (s_baseline*15 + lux)/16; /* 环境慢漂移 EMA */
    } /* SHADED 态基线冻结，防遮住期间基准塌陷 */
    if (s_baseline > 0 && (float)lux < s_baseline)
        drop = (int32_t)((s_baseline - lux) * 100 / s_baseline);
    int32_t th = (s_state == SHADE_CLEAR) ? SHADE_DROP_PERCENT : SHADE_RELEASE_PERCENT;
    uint8_t hit = (s_state == SHADE_CLEAR) ? (drop >= th) : (drop < th);
    if (hit) { if (++s_confirm >= SHADE_CONFIRM_N) {
                   s_confirm = 0;
                   s_state = (s_state == SHADE_CLEAR) ? SHADE_SHADED : SHADE_CLEAR;
                   return (s_state == SHADE_SHADED) ? 1 : -1; } }
    else s_confirm = 0;
    return 0;
}
```
- 本步边沿只记状态/刷新 OLED（`S:CL/SD` + drop% 便于调参）；**CAN 上报等第2步**。
  > 2026-09-06 落地注：状态机实现于 `Core/{Inc,Src}/shade.{c,h}`；BH1750_Task 每周期喂 lux、边沿直接发 0x200（阶段3 提前联动），OLED 行2 现显示 `Lux:%u D:%u%%`。
- **验收**：手遮 ~1s 内翻 SHADED、移开回 CLEAR；快速抖动手掌不翻转；开灯变亮不误触发。敏感度不合现场时只调 `config.h` 三个宏。

### P1-06 SG90 PWM 添加与本地自检 ⬜
1. CubeMX：TIM2 → Channel1 = PWM Output CH1，引脚 PA0；PSC=71、ARR=19999（72MHz/72/20000=50Hz）。
2. 生成后确认 `MX_TIM2_Init()` 被调用，初始化后执行一次 `HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1)`（**只调一次**，此后只改 CCR）。
3. **本地自检**（临时，`#define SG90_SELFTEST 1` 控制上电执行一次）：缓动到 `GATE_OPEN_CCR` 保持 2s → 缓动回 `GATE_CLOSE_CCR`。自检循环内每 20ms 调一次 `Gate_StepTo()`；第2步起由 CAN 指令侧以同周期调用（复用同一函数，不改签名）：
```c
/* 每 20ms 调一次，向目标步进 ±100µs，到位即停，避免高频突变 CCR 引抖动 */
void Gate_StepTo(uint16_t target_ccr);
```
- **验收**：上电自检舵机 0°→90°→0° 平稳、无抖动啸叫；独立 5~6V 供电确认（接 MCU 5V 会复位/发烫）。
