# C8T6 下位机实现步骤（FreeRTOS 三阶段）

> 工程：`c8t6/`（STM32F103C8T6 + CubeIDE + FreeRTOS CMSIS_V2）
> 角色：停车场 Demo **CAN 从节点**。上位机 = MP157 M4（FDCAN1，只收）。
> 本文档分**三阶段**实现（逐步验收），最终功能：
> ① **BH1750 遮光检测**——用**百分比掉点**方式判遮光（敏感度在 `config.h` 配置），遮光 → 经 **CAN 发报文**上报上位机；
> ② 收到上位机**开闸 CAN 帧** → 控制 **SG90** 转动；
> ③ **OLED 实时显示**状态。

---

## 0. 现状（代码已到哪）
- 软件 I2C（`sw_i2c`，PB8=SCL/PB9=SDA，GPIO 开漏）驱动 **OLED(SSD1306 0x3C)** 已点亮；显示 API：`SSD1306_ShowChar/ShowString(line 1~4, column 1~16)` + `SSD1306_UpdateScreen()`。
- `BH1750` 驱动已就绪（`BH1750_ReadLux(&lux)`，错误时 `lux=0xFFFF`），**BH1750_Task 目前挂起**（`osThreadSuspend(NULL)`）。
- `CAN1`（bxCAN，500k，PA11=RX/PA12=TX → TJA1050）已 `MX_CAN_Init()`，**尚未配过滤器/Start**。
- FreeRTOS 任务：`defaultTask`（诊断 LED）、`CAN_Rx_Task`、`BH1750_Task`、`OLED_Task`；互斥 `OledMutex`；队列 `BhDataQueue`(8×uint16)。
- OLED 界面 4 行宏：`OLED_LINE_TITLE=1 / LUX=2 / GATE=3 / CAN=4`。
- `main.c` USER CODE 2 目前是**裸机诊断**（`g_DiagCode` 等，屏亮后可拆）。

## 1. 硬件接线
| 器件 | 引脚 | 说明 |
|---|---|---|
| OLED SSD1306 | PB8=SCL, PB9=SDA（软件 I2C），VCC 3.3V，GND | 地址 0x3C（写 0x78），模块自带 4.7k 上拉 |
| BH1750 | **同一条总线** PB8/PB9，VCC 3.3V，GND | 地址 0x23/0x5C，与 OLED 共用不冲突 |

| PC13 | 板载 LED（心跳/诊断） | 可留 |

## 阶段 1：FreeRTOS + 单 OLED（✅ 主体已完成，验证/收尾）
1. **验证**：编译烧录 → 屏常显 `HelloWorld`（`OLED_Task` 每秒刷新）。PC13 闪烁 = 诊断码：**闪 6 下 = 总线健康+OLED 在线**（其余见 `sw_i2c` 诊断说明）。
2. **收尾**（可选）：稳定后可把 `main.c` USER CODE 2 的裸机诊断（`SW_I2C_LineCheck/Probe`、`g_DiagCode`）删掉，只保留必要的 `SSD1306_Init`。
3. 建立 **`config.h`**（放 `Core/Inc/`，下文"5. config.h"），先把显示/采样相关常量收进去，后面阶段逐步使用。
4. **验收**：开机即显示、无残影、LED 不报错码。

## 阶段 2：OLED + BH1750（遮光百分比检测）
1. **取消 BH1750_Task 挂起**：删掉任务开头 `osThreadSuspend(NULL);`。
2. **BH1750_Task 逻辑**（采样周期 `SHADE_SAMPLE_MS`，建议 200ms）：
   ```
   每次：
     BH1750_ReadLux(&lux)         // 失败(0xFFFF)：CAN 行报传感器故障，跳过本次
     lux 入 BhDataQueue（满丢旧）  // 供 OLED 显示
     跑遮光状态机（见下），状态边沿触发动作（阶段3才发 CAN）
   ```
3. **遮光状态机（百分比掉点 + 去抖）**：
   ```
   状态 CLEAR：
     baseline 慢跟踪：baseline = (15*baseline + lux)/16      // 环境光基准 EMA
     若 lux > baseline：baseline = lux                        // 开灯/变亮快速跟上
     计算 drop% = (baseline - lux)*100 / baseline（lux≥baseline 时按 0）
     若 drop% >= SHADE_DROP_PERCENT 连续 SHADE_CONFIRM_N 次
         → 进入 SHADED（边沿：上报"遮光/车到位"）
   状态 SHADED：
     不再更新 baseline（防遮住后基准塌陷）
     drop% < SHADE_RELEASE_PERCENT 且持续 SHADE_CONFIRM_N 次
         → 回 CLEAR（边沿：上报"恢复"）
   ```
   要点：**只在边沿动作一次**，遮住期间不重复触发（防抖）；`drop%` 抗环境慢漂移，比绝对 lux 阈值稳。
4. **OLED 显示**（`OLED_Task`，拿队列值刷新）：
   ```
   Line1 TITLE: "PARK NODE"
   Line2 LUX  : "Lux:12345 D:78%"     // 当前 lux + drop%
   Line3 GATE : "Gate:CLOSE"          // 阶段3用
   Line4 CAN  : "CAN:---"             // 阶段3用
   ```
   注意 `SSD1306_ShowString` 只改显存，改完整行用空格补足 16 列防残影，最后 `SSD1306_UpdateScreen()`。
5. **验收**：手遮/光变 → OLED 的 lux、drop% 实时变；稳定遮蔽 → 状态在 OLED（可临时加一行显示 SHADED/CLEAR）翻转；抖动手电不误触发。

## 阶段 3：OLED + BH1750 + CAN + SG90
### 3.1 CAN 收（上位机指令）
1. CubeMX 确认 CAN1=Normal、500k（Prescaler=9/Seg1=5/Seg2=2 等值见工程）；`MX_CAN_Init()` 已调用。
2. `main.c` USER CODE 2（调度器启动前）加 **过滤器 + Start + 开 RX 中断**（bxCAN）：
   ```c
   CAN_FilterTypeDef f;
   f.FilterIdHigh      = (0x100u << 5);      /* 收标准帧 ID=0x100 开闸指令 */
   f.FilterIdLow       = 0u;
   f.FilterMaskIdHigh  = (0x7FFu << 5);      /* 掩码，精确匹配（想收 0x1xx 可放宽） */
   f.FilterMaskIdLow   = 0u;
   f.FilterFIFOAssignment = CAN_RX_FIFO0;
   f.FilterBank        = 0u;
   f.FilterMode        = CAN_FILTERMODE_IDMASK;
   f.FilterScale       = CAN_FILTERSCALE_32BIT;
   f.FilterActivation  = CAN_FILTER_ENABLE;
   HAL_CAN_ConfigFilter(&hcan, &f);
   HAL_CAN_Start(&hcan);
   HAL_CAN_ActivateNotification(&hcan, CAN_IT_RX_FIFO0_MSG_PENDING);
   ```
3. 中断回调（`stm32f1xx_it.c` 的 `USB_LP_CAN1_RX0_IRQHandler` 已在，CubeMX 已生成）：
   ```c
   void HAL_CAN_RxFifo0MsgPendingCallback(CAN_HandleTypeDef *h)
   {
     CAN_RxHeaderTypeDef rh; uint8_t data[8];
     HAL_CAN_GetRxMessage(h, CAN_RX_FIFO0, &rh, data);
     /* data[0]：0x01=开闸 0x02=关闸 0x10=查询 —— 入指令队列或直接置 gate 目标 */
   }
   ```
   更 FreeRTOS 的做法：回调里只置标志/入队，SG90 动作放在任务里。
### 3.2 CAN 发（遮光上报）
- 遮光状态机 **CLEAR→SHADED 边沿** 时（阶段 2 的"上报"位）发 `0x200`：
  ```c
  CAN_TxHeaderTypeDef th = {0};
  uint8_t data[8] = {0};
  th.StdId = 0x200; th.IDE = CAN_ID_STD; th.RTR = CAN_RTR_DATA; th.DLC = 8;
  data[0] = 0x01;                       /* 事件：1=遮光/车到位 0=恢复 */
  data[1] = (uint8_t)(lux >> 8); data[2] = (uint8_t)(lux & 0xFF);  /* lux */
  data[3] = (uint8_t)drop_percent;      /* 掉点百分比 */
  uint32_t mb; HAL_CAN_AddTxMessage(&hcan, &th, data, &mb);
  ```
  SHADED→CLEAR 边沿再发一帧 `data[0]=0x00`（恢复）。
### 3.3 SG90 开闸
1. CubeMX：加一个 TIM（建议 TIM2，Channel1 PWM，引脚 PA0），PSC=71、ARR=19999 → **50Hz/20ms**；TIM 时钟 72MHz。
2. 用 CCR 控制角度（值=脉宽µs）：关闸 0°≈500、开闸 90°≈1500、180°≈2500；建议 open/close 宏放 config.h。
3. 收到开闸指令 → `__HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, GATE_OPEN_CCR);` 转 90°（到位可 `HAL_Delay` 或软延时保持）；关闸同理。
   - 动作放任务里（CAN_Rx_Task 或独立 GateTask），不要在 ISR 里占用。
   - SG90 只接受 50Hz 脉冲，别在循环里高频改 CCR。
### 3.4 OLED 全状态显示
- Line3 GATE：`Open/Close`（跟 3.3 状态）
- Line4 CAN ：`CAN:OK`（启动后）、遮光事件时闪烁显示 `EVT!` 一秒；CAN 错误可显示 `CAN:ERR`
- 全程 `OledMutex` 保护，各任务只改显存、集中在 OLED_Task 上屏（或上屏也加锁）。

### 3.5 验收
- 遮挡 BH1750（低于阈值持续去抖时间）→ C8T6 发 `0x200`（上位机 CAN 工具/M4 收到），OLED 显示遮光事件；
- 上位机发 `0x100, data[0]=0x01` → SG90 转到开闸位，OLED Gate 行变 Open；
- 发 `0x02` → 回位 Close；恢复光照 → 发 0x200 data[0]=0x00。

## 4. CAN 帧约定（与 docs/protocols.md 最终对齐）
| 方向 | ID | 数据 | 含义 |
|---|---|---|---|
| 主→从 | 0x100 | `[0] cmd`（0x01 开闸 / 0x02 关闸 / 0x10 查询） | 指令 |
| 从→主 | 0x200 | `[0] event`（0x01 遮光/车到位, 0x00 恢复） `[1..2] lux hi/lo` `[3] drop%` | 事件上报 |
| 从→主 | 0x210（可选） | 心跳/状态周期 | 断线检测 |

## 5. config.h（新建于 Core/Inc，供各文件 include）
```c
#ifndef __CONFIG_H
#define __CONFIG_H

/* ---- 遮光检测（阶段2/3 使用；按现场光环境调） ---- */
#define SHADE_SAMPLE_MS        200u   /* 采样周期 ms */
#define SHADE_DROP_PERCENT     60u    /* 敏感度：lux 相对基线掉 ≥60% 视为遮光 */
#define SHADE_RELEASE_PERCENT  20u    /* 掉点 <20% 视为恢复（回滞防抖） */
#define SHADE_CONFIRM_N        3u     /* 连续 N 次满足才翻转（去抖） */

/* ---- CAN ---- */
#define CAN_CMD_ID             0x100u /* 主→从 指令 */
#define CAN_EVT_ID             0x200u /* 从→主 事件 */
#define CAN_HEARTBEAT_ID       0x210u /* 从→主 心跳（可选） */

/* ---- SG90（50Hz，CCR 值 = 脉宽 µs @1MHz 计数） ---- */
#define SG90_TIM               htim2
#define SG90_CHANNEL           TIM_CHANNEL_1
#define GATE_CLOSE_CCR         500u    /* 0°   关闸 */
#define GATE_OPEN_CCR          1500u   /* 90°  开闸 */

/* ---- OLED 显示周期 ---- */
#define OLED_REFRESH_MS        200u
#define OLED_LINE_TITLE        1u
#define OLED_LINE_LUX          2u
#define OLED_LINE_GATE         3u
#define OLED_LINE_CAN          4u

#endif /* __CONFIG_H */
```
> 说明：`OLED_LINE_*` 目前在 `freertos.c` 里定义，建议收拢到本文件；BH1750 地址在 `bh1750.h`、sw_i2c 引脚在 `sw_i2c.h`，不重复。

## 7. 排障速查
| 现象 | 查 |
|---|---|
| OLED 黑屏/残影 | 上电时序 20ms、init 平铺序列（参考工程 OLED_Config）；PB8/PB9 上拉；模块供电 |
| 遮光不触发/误触发 | 调 `SHADE_DROP_PERCENT`/`CONFIRM_N`；看 OLED drop% 数值是否贴合现场 |
| CAN 收不到 | 两端都 500k；过滤掩码；`HAL_CAN_Start`；CANH/CANL 反接；120Ω |
| SG90 不动/抖 | 50Hz 确认（PSC/ARR）；CCR 范围 500~2500；5~6V 供电共地 |
| LED 闪诊断码 | 闪 6=总线+OLED OK；其它按 `sw_i2c` 表查（1/3 GPIO、2/4 线、5 无 ACK） |
