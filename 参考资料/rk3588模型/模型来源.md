# RK3588 车牌识别模型归档（2026-09-26）

## 结论速查

- **现成 .rknn 没有官方发布**。Rockchip 官方 `airockchip/rknn_model_zoo` 只有
  `examples/LPRNet/`（onnx + convert 脚本），仓库与 Releases 均不含 .rknn。
- 本目录的 `lprnet.onnx` **就是官方 zoo 发布的那份**（CCPD LPRNet，输入 1x3x24x94、
  输出 1x68x18 CTC、67 字符+blank），官方直链：
  `https://ftrg.zbox.filez.com/v2/delivery/data/95f00b0fc900458ba134f8b180b3f7a1/examples/LPRNet/lprnet.onnx`
  （即 zoo 里 `examples/LPRNet/model/download_model.sh` 的内容）
- GitHub 上唯一带现成 .rknn 的仓库是 `cqu20160901/LPRNet_rknn_Cplusplus`
  （7 星、2024-07 停更、作者自曝 RK3588 算子回落 CPU 坑），不值得换。
- "检测+识别"一体的现成 rknn 不存在；社区配方 = YOLOv5s/v8n(CCPD) + LPRNet，需自训自转。

## 板上 lprnet.rknn 再生配方（rknn-toolkit2 2.3.2）

```python
from rknn.api import RKNN
r = RKNN(verbose=False)
r.config(mean_values=[[127.5]*3], std_values=[[127.5]*3], target_platform='rk3588')
assert r.load_onnx(model='lprnet.onnx') == 0
assert r.build(do_quantization=False) == 0
assert r.export_rknn('lprnet.rknn') == 0
```

板上部署路径 `/root/models/lprnet.rknn`；字符表标定见 `rk3588_service/lpr_decode.py`。
原 `lprnet.rknn` 归档时留在板上（Tailscale 不在线没拉回来），用上面配方数秒可再生成。

  `https://raw.githubusercontent.com/we0091234/yolov8-plate/master/weights/yolov8s.pt`
- 流程：pt 在 PC 端 `YOLO('yolov8s.pt').export(format='onnx', imgsz=640)`

  mean 0 / std 255、FP16、zoo yolov8 惯例）。

  同一图片整帧直喂 LPRNet = J88E（错误）——两段式收益实锤。

## 评估过、不采用（2026-09-26 A/B 实测）

  宣传 mAP@0.5=0.994，但对"车牌占画面大"的图（川A88888 原图占 77%、

  训练分布太窄（CCPD 裁切风）。已 A/B 实锤，勿再考虑。**权重已从本目录
  删除**（勿再下载浪费空间），板上留有 `/root/models/carplate_yolov8n.rknn`
  备查。教训：检测模型选型看实测分布，不看宣传指标。

## HyperLPR3 A/B（2026-09-26，结论：9/9 全胜）

离线安装（板子当时无外网）：台式机 `pip download hyperlpr3 --no-deps` +
模型包 `http://hyperlpr.tunm.top/raw/20230229.zip`（12.4MB），scp 上板后
`pip3 install --break-system-packages --no-deps`，模型解到 `~/.hyperlpr3/`。

- 板端 CPU onnxruntime **68.8ms/帧**（自带 y5fu 检测 + RPNet v3 识别），
  对 3s 识别周期毫无压力。
- **9/9 测试图全对**：川A88888 0.999 / 鲁B325DE 0.997 / **京AD06088 0.993
  （LPRNet 认成津，HyperLPR3 认对，还给出 type=3 绿牌）**，且 v18 缩到 14%、
  旋转 8° 全部正确——**LPRNet 的掉尾字问题它也一并解决**（识别输入宽 160
  vs 94 + 多字典训练）。
- 结果元组口径：`(plate_str, conf, type_int, [x1,y1,x2,y2])`（type 0=蓝牌
  3=绿牌）；板上对拍脚本 `rk3588_service/tests/itest_hyperlpr3.py`。
- Apache-2.0 协议干净；**已切换为生产引擎（2026-09-26）**：`edge_hub
  --engine hyperlpr3`（systemd 默认），LPRNet 保留为 `--engine lprnet`
  回退；回归脚本 `tests/itest_hyperlpr3.py`（走生产包装类
  `lpr_server.HyperLpr3Recognizer`）。
